# Baton — instructions for a new LLM

**First read [START_HERE.md](START_HERE.md).** It is the short, stable question-first route to the actual code and known corrections. Do not treat `main`'s legacy relay README as the newer Desktop/Core implementation. The [longer newcomer guide](https://github.com/martintommerstigen/Baton/blob/docs/eik-repository-onboarding-2026-11-11/docs/START_HERE_NEW_LLM.md) and [dated PR lifecycle map](https://github.com/martintommerstigen/Baton/blob/docs/eik-repository-onboarding-2026-11-11/docs/2026-11-12_BATON_PR_LIFECYCLE_INDEX.json) are draft-branch sources, not live installation status.

- Before repeating an investigation, read the exact prior source and its correction. Report only what genuinely changed.
- Preserve **author → repo → exact ref/path/blob → test → correction**. Separate queued, delivered, received, processed, replied and closed; ACK or a source-reloaded chat reply is not proof of a running model or terminal access.
- Distinguish `reported/implemented-unverified/tested-simulated/tested-live/blocked`. A branch, draft PR or CI pass is not a deployed Greg application.
- Respect `PAUSE_UI_WRITES`, consent, revocation, least privilege and no blind resend on uncertain delivery. Only Skin talks to Core; only Core changes Core.
- Baton is **public**; GTRCM is **private**. RustWorld is a historical GTRCM branch. Never publish private source, transcripts, credentials or identifiers.

This file intentionally excludes accumulating dated status reports. Use the linked originals and current GitHub metadata.
