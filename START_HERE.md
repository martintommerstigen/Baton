**New LLM? Read the [90-second task card](docs/NEW_LLM_90_SECOND.md) first.** Do not assume an inbound invitation supplies an outbound tool, an authenticated sender or permission to control Greg.

**Branch inventory:** [2026-11-13 snapshot of all 102 Baton branch names](docs/BRANCH_NAME_INVENTORY.json), retrieved with cursor pagination. It is a name index, **not** a code audit or deployment certificate; compare [live branches](https://github.com/martintommerstigen/Baton/branches) and relevant original tests.

**Live snapshot-delta check (read-only):** run `python3 branch_inventory_delta.py docs/BRANCH_NAME_INVENTORY.json` on a checkout. [Source](branch_inventory_delta.py) and [five offline negative/pagination tests](test_branch_inventory_delta.py) compare live branch *names* with this dated inventory and report added/missing names. A private GTRCM comparison requires a read-scoped `GITHUB_TOKEN` in the environment and the GTRCM snapshot path; never commit or paste the token. This does not inspect branch contents, PR corrections or Greg.

**Not every investigation has a PR.** Search [all branches](https://github.com/martintommerstigen/Baton/branches) as well as [all PRs](https://github.com/martintommerstigen/Baton/pulls?q=is%3Apr), compare relevant branch heads with `main`, and read the earliest tests before attributing a result to a later synthesis. In particular, the resource-scope trial above is an independent branch, not deployed Baton.

**Before claiming anything new:** locate the earliest checked original, later correction, exact Git ref/path/blob SHA and negative tests. Mark `reported`, `implemented-unverified`, `tested-simulated`, `tested-live` or `blocked`. Source claims about Greg are not a substitute for independent current installation inspection.

**Non-negotiable operating boundary:** Only Skin talks to Core; only Core changes Core. Respect `PAUSE_UI_WRITES`, consent, revocation, least privilege, and no blind resend after uncertain delivery. Chat URLs are addresses, not persistent identities. Public Baton must not contain private GTRCM bodies, transcripts or secrets.
