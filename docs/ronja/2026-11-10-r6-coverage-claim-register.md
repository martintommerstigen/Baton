## Software and tests

[tools/gtrcm_branch_audit.py](../../tools/gtrcm_branch_audit.py) is a **read-only** Python 3 stdlib tool. It fetches every branch tip, its exact commit timestamp, and every recursive tree; rechecks the branch set and SHAs before returning a result. It fails rather than silently claiming coverage if pagination duplicates, a tree is truncated, the branch set changes, a date is missing or output exists. It does not execute fetched source or write to GitHub. An optional environment token is only used in an in-memory HTTP header, not stored or logged; no GitHub secret is provisioned for the remote agent. Without adequate API quota, it fails and preserves prior output rather than automatically retrying.

**Evidence:** seven isolated offline Python tests passed in the local container; [GitHub Actions 42854392071](https://github.com/martintommerstigen/Baton/actions/runs/42854392071) passed the branch's discovery suite and compile step at commit 6fe2d75. Later index-only commits do not change executable code. **No live GitHub HTTP run of this new CLI** is claimed; the full static 276-tip tree and date inventory was separately assembled from authenticated GitHub read operations.
