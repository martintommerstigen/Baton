## Exact B5-RJ16 delta

**Already done:** R21 connection-time SO_PEERCRED and delegated-FD negative; R22 single-use SQLite source witness; B1 SQLite replay, pause and durable begin_click→uncertain.

**Implemented:** [frame_credentials.py](../../remote_security/frame_credentials.py) requires SO_PASSCRED on the listener *before accept*, then recvmsg with SCM_CREDENTIALS on **every** frame segment. Kernel sender PID and UID must match the original connector's PID and UID. Fork/FD delegation, mixed writers, root, unknown UID, TCP, missing/truncated credentials, oversized/multiple/partial frames and deadline expiry are rejected. The opt-in CredentialBoundBrokerHandler invokes only the existing B1/R22 request_from_socket, checking B1 endpoint identity before/after; it never authorizes UI Send, a general shell, or an external listener. The installer refuses unscoped stores.

**Limitations:** Linux process identity is not ChatGPT authorship; privileged CAP_SYS_ADMIN credential spoofing, compromised same-process code, source DOM forgery and browser CDP write capability are outside this narrow protection. A frame queued before listener SO_PASSCRED may lack valid credentials and must be denied, never blindly retried. Configure an unstarted broker before accepting clients; B1 remains owner of socket lifecycle, PAUSE_UI_WRITES, SQLite and uncertain delivery. Do not hot-swap a running handler.
