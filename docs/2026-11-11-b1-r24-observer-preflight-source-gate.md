## Implemented boundary and falsifier

`run_b1_snapshot_observer.py` now requires independently supplied `--collector-pid`, `--collector-uid`, `--browser-profile`, `--snapshot-socket`, `--cdp-host` and `--cdp-port`. No value is learned from untrusted ChatGPT text. Before the first snapshot and before **each** subsequent snapshot or R22 witness request, it calls Ronja's pinned R24 `audit_observer_boundary` under the observer UID. A missing import, denied kernel check, unexpected schema, missing required check, active/unknown `PAUSE_UI_WRITES` or changed pause fails closed. R23 still authenticates the actual AF_UNIX peer; R22 remains the sole witness owner. No new network listener or CDP client is created.

**Negative controls:** reject missing/false preflight result, absent profile/CDP/socket/network check, duplicate checks, same-UID collector through the real pinned R24 implementation, pause flip during preflight, and post-witness isolation failure. The last case is `SnapshotUncertain`, not a retry; a boundary failure before the witness never sends the witness. A successful check remains `scoped_preflight_pass_not_attestation`, not `tested-live`.

**Dependency pin:** R24 `1a52dc5b03acef2f6ba4621bc4edbec2413eed0f` and R23 `961f49a7230c65e479cb252a33a38fee634b5a2e` are separate GitHub Actions checkouts. No Ronja-owned source is copied into B1's branch. No new third-party software is introduced: this B1 delta uses Python standard library and existing repository components; the existing Playwright dependency remains limited to the collector. OpenSSH and WireGuard were not imported or relicensed in this change. No new public shell endpoint is introduced.

**Important limits:** R24 is a declared-endpoint, point-in-time preflight. It cannot prove that undeclared CDP endpoints, future descriptor passing, profile aliases, a compromised collector, PID reuse, or post-check policy changes are impossible. Rechecking reduces but cannot eliminate time-of-check/time-of-use gaps. Neither a preflight nor a source snapshot authenticates a ChatGPT author or proves A→B→C. A real authorized Greg test must independently establish collector/observer process and OS policy, pause state, actual browser source/target IDs, and new assistant turn IDs before any live claim.
