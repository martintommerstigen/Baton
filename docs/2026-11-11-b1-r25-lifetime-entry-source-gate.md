## Free software and deployment boundary

[libseccomp](https://github.com/seccomp/libseccomp) is LGPL-2.1; H24 uses the existing system `libseccomp.so.2` via Ronja's ctypes binding, **not vendored code**. [OpenSSH](https://www.openssh.org/) uses BSD-style licensing and can provide a restricted authorized transport; [WireGuard](https://www.wireguard.com/) kernel code is GPLv2, with other components under differing free licenses. Neither is added to this change. This is a Linux-local security gate, not a new public network listener, remote shell, or a license transfer. Before Greg deployment, check the installed library/package license and source integrity.
